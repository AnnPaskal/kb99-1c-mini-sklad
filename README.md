# Как запустить базу
1. Запустите «1С:Предприятие» (ярлык запуска 1С, обычно называется 1C:Enterprise или 1cv8).
2. В появившемся списке информационных баз нажмите кнопку «Добавить».
3. В окне создания/добавления выберите пункт «Добавление в список существующей информационной базы» и нажмите «Далее».
4. Задайте имя базы (как она будет отображаться в списке) и выберите тип расположения — «На данном компьютере или на компьютерах в локальной сети» (файловый вариант).
5. В поле «Каталог информационной базы» нажмите на кнопку с многоточием (...) и укажите папку на диске, в которой лежит файл базы 1Cv8.1CD. Нажмите «Далее», а затем «Готово».
6. Выберите добавленную базу из списка и нажмите кнопку «1С:Предприятие» (для работы) или «Конфигуратор» (если нужны права администратора и изменение структуры).
7. Заполните справочники необходимыми данными для дальнейшей работы.
