# Как запустить базу
1. Запустите «1С:Предприятие» (ярлык запуска 1С, обычно называется 1C:Enterprise или 1cv8).
2. В открывшемся окне выберите вариант «Создание новой информационной базы» и нажмите «Далее».
3. Выберите пункт «Создание базы без конфигурации...» (чтобы развернуть чистую базу под вашу конфигурацию) или из шаблона (если устанавливаете типовую конфигурацию).
4. Введите наименование базы (произвольное имя, которое будет отображаться в списке).
В зависимости от того, какой у вас файл-источник, выберите один из двух вариантов:
Вариант А: Загрузка файла конфигурации (.cf)
1. В списке баз выделите созданную пустую базу и нажмите «Конфигуратор» (запуск с правами администратора).
2. В верхнем меню выберите Конфигурация -> Открыть конфигурацию (если она еще не открыта).
3. Перейдите в меню Конфигурация -> Загрузить конфигурацию из файла...
4. Укажите путь к вашему файлу с расширением .cf и нажмите «Открыть».
5. Дождитесь окончания загрузки. В появившемся окне с вопросом «Обновить конфигурацию информационной базы?» нажмите «Да».
6. В окне «Реструктуризация информационной базы» нажмите «Принять».
Вариант Б: Загрузка полной информационной базы (.dt)
1. В списке баз запустите созданную базу в режиме «Конфигуратор».
2. В верхнем меню выберите Администрирование -> Загрузить информационную базу...
3. Выберите файл резервной копии с расширением .dt и нажмите «Открыть».
4. Подтвердите выполнение операции (система предупредит, что текущие данные будут перезаписаны).
5. Дождитесь сообщения об успешной загрузке и закройте Конфигуратор.

Если вы создаете базу на основе шаблона или она уже расположена на вашем устройстве,
то в окне создания/добавления выберите пункт «Добавление в список существующей информационной базы» 
и нажмите «Далее».
1. Задайте имя базы (как она будет отображаться в списке) и выберите тип расположения — «На данном компьютере или на компьютерах в локальной сети» (файловый вариант).
2. В поле «Каталог информационной базы» нажмите на кнопку с многоточием (...) и укажите папку на диске, в которой лежит файл базы 1Cv8.1CD. Нажмите «Далее», а затем «Готово».
3. Выберите добавленную базу из списка и нажмите кнопку «1С:Предприятие» (для работы) или «Конфигуратор» (если нужны права администратора и изменение структуры).
4. Заполните справочники необходимыми данными для дальнейшей работы.
