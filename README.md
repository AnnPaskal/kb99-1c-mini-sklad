# Как запустить базу
1. Запустите 1С Предприятие.
2. Добавьте пустую базу в список.
3. Запустите ее через конфигуратор.
4. В разделе «Конфигурация» нажмите «Загрузить конфигурацию из файла» и выберите нужный файл.
5. Согласитесь на замену данных и обновите конфигурацию.
