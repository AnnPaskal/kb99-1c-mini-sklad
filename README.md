# Как запустить базу
* Запустите 1С Предприятие.
* Добавьте пустую базу в список.
* Запустите ее через конфигуратор.
* В разделе «Конфигурация» нажмите «Загрузить конфигурацию из файла» и выберите нужный файл.
* Согласитесь на замену данных и обновите конфигурацию.
